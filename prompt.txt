Project Overview
Create a modern, elegant, and fully responsive e-commerce website for "Pure Nature" – a brand that sells organic, handmade products including skincare, herbal oils, natural soaps, organic foods, and herbal teas.

The website should have a warm, natural, premium feel with earth tones (primarily a sage green color #6B7C5B and soft cream background #F5F3F0). It must be 100% mobile responsive and work perfectly on all devices (phones, tablets, desktops).

Branding & Visual Identity
Logo: Use a local image file named logo.png displayed in the navigation bar instead of text.

Color Palette:

Primary Brand Color: Sage Green (#6B7C5B)

Secondary Background: Soft Cream (#F5F3F0)

Accent Color: Golden Yellow (for buttons and highlights)

Text: Dark gray for readability, white on dark backgrounds

Fonts:

Headings: Playfair Display (serif, elegant)

Body text: Inter (sans-serif, clean)

Brand name special font: Pacifico (for visual identity if needed)

Technical Requirements (Simplified)
Use Tailwind CSS for styling (included via CDN)

Use Remix Icon for icons (included via CDN)

Google Fonts for Playfair Display, Inter, and Pacifico

No external dependencies beyond these

Fully functional with pure HTML/CSS/JavaScript

No backend required – WhatsApp integration handles orders

All images must use local file names (no readdy.ai or external image URLs)

Layout Rules
Product Grid: 3 columns on desktop, 2 on tablet, 1 on mobile

Cards: Not full width – centered with reasonable max-width, consistent sizing

Spacing: Generous padding between sections (py-20 typically)

Rounded corners: Consistent use of rounded-xl, rounded-2xl for cards and buttons

Container: Centered content with max-width on most sections except product grid which can be slightly wider

The Goal
Build a beautiful, trustworthy, nature-inspired e-commerce website that makes customers feel confident buying organic products. The site should feel premium, clean, and easy to navigate. Every product click leads to a detailed view, and every purchase goes through WhatsApp for simple order management.
